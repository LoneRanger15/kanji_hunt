# 🎌 KanjiHunt

![KanjiHunt Demo](<img width="720" height="1600" alt="1000154720-ezgif com-video-to-gif-converter" src="https://github.com/user-attachments/assets/c4080aa1-a64d-43e4-b184-9a3668e60813" />)

KanjiHunt is a Flutter-based mobile application that helps users learn Japanese kanji through real-world object recognition. Using Google ML Kit, the app detects objects through the camera and maps them to their corresponding Japanese kanji, making vocabulary learning more interactive and engaging.

---

## ✨ Features

- Real-time object detection
- Japanese kanji association
- Kanji stroke order visualization
- Reward and progress tracking
- Animated user interface
- Local data storage
- Beginner-friendly learning experience

## 🚀 How It Works

1. Open the application.
2. Point the camera at an object.
3. Google ML Kit detects the object.
4. The app matches the object with a Japanese kanji.
5. Users can view:
   - Kanji
   - Meaning
   - Reading
   - Stroke Order
6. Earn rewards and track discovered kanji.

## 🎯 Motivation

Many language learning apps rely on flashcards and memorization. KanjiHunt takes a different approach by connecting Japanese kanji with real-world objects, helping learners build stronger visual associations and improve retention.
